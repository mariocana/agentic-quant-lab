// ExportBars: esporta le barre del grafico in CSV per quantlake.
// MultiCharts gira su un PC Windows separato. Due modi per far arrivare il file al Mac:
//  A) (consigliato) cartella condivisa dal Mac via SMB: sul Mac
//     Impostazioni di Sistema > Generali > Condivisione > Condivisione file, aggiungi la
//     cartella python/quantlake/data/multicharts. Su Windows apri \\<IP del Mac>\multicharts
//     una volta con le credenziali del Mac. Il FilePath sotto punta lì: il file è sempre aggiornato.
//  B) cartella locale (es. C:\Dati) e copia a mano sul Mac in python/quantlake/data/multicharts.
// Due usi, stesso indicatore (cambia solo FilePath e la storia caricata nel grafico).
// Sessione sempre 17:00-16:00 CT senza pause, Time Zone Exchange. Passo passo: applications/MULTICHARTS_EXPORT.md
//  1) STORICO (una volta, e dopo ogni rollover trimestrale): @ES 1 minuto, storia dal 2016,
//     FilePath ...\ES_1min.csv (NQ: ...\NQ_1min.csv). Poi sul Mac: multicharts.py --replace,
//     poi ohlcv_gold.py (con --full le righe del vecchio export resterebbero sul vecchio aggiustamento).
//  2) RECENTE (ogni giorno, workspace "Export"): @ES e @NQ 1 minuto, Format Instrument >
//     Data Range "5 days back", FilePath ...\ES_recent.csv e ...\NQ_recent.csv.
//     Si scrive in pochi secondi all'apertura del workspace; resta attivo finché il grafico
//     è aperto (ad ogni barra chiusa aggiunge una riga). Il Mac lo riscrive per intero ogni volta.
Inputs: FilePath("\\192.168.1.X\multicharts\ES_1min.csv"); // IP del Mac al posto di X, oppure "C:\Dati\ES_1min.csv"
Vars: riga("");

once begin
    FileDelete(FilePath);
    FileAppend(FilePath, "date,time,open,high,low,close,volume,ticks,upticks,downticks" + NewLine);
end;

if BarStatus(1) = 2 then begin
    riga = NumToStr(Date + 19000000, 0) + "," + NumToStr(Time, 0) + ","
         + NumToStr(Open, 2) + "," + NumToStr(High, 2) + ","
         + NumToStr(Low, 2) + "," + NumToStr(Close, 2) + ","
         + NumToStr(Volume, 0) + "," + NumToStr(Ticks, 0) + ","
         + NumToStr(UpTicks, 0) + "," + NumToStr(DownTicks, 0);
    FileAppend(FilePath, riga + NewLine);
end;
