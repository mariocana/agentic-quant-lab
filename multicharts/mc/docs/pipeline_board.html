    Spec

    Meccanica
    1 contratto, 100 gg: trade dove previsto, 1/giorno, flat, P&L ×10 con 10 contratti

    n ≥ 200 · avg trade ≥ $70 (NQ) · PF ≥ 1.2 · WR ≥ 55% · R:R 0.5–1 · DD÷10 ≤ $1.250 · peggior trade÷10 ≤ $500 · nessun anno > 50%

    Monte Carlo
    Reshuffle 1000: mediana > 0 · < 10% sim negative · DD 95°÷10 ≤ $2.500

    Solo IS, split‑sample, ≤ 3 input, cluster; ripetere gate 2 e 3
  6. 5
    OOS
    Una volta: avg trade/WR/PF stesso ordine · WR ≥ 50% · DD ≤ 1.5× IS · fail = cimitero

    Bootstrap
    EV > 0 in $ e R · P(EV≤0) < 5% IS, < 10% OOS · CI sovrapposti · percentili DD salvati
