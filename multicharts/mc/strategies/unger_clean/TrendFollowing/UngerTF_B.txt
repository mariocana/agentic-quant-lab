{ Mario_UngerTF_B — Trend Following di Unger, variante B (intraday, "DevelopID",
  video 4x04), per futures. Richiede la funzione Mario_PtnBaseSA. Spec: SPEC.md.

  Regole di Unger ai parametri finali (vedi UngerTF_ID.txt per la trascrizione fedele):
    finestra MyStartTrade -> MyEndTrade;
    long  se pattern 1 (ieri corpo < 50% del range) e non 35 (oggi non inside)
          -> buy stop al massimo di oggi; short, stesse condizioni -> sellshort stop al minimo;
    stop e target fissi; flat a fine sessione.

  Cosa cambia rispetto al forex di Unger:
    - Orari nel fuso dell'exchange del chart. Unger: 03:00-05:00 New York.
        @EC, @ES, @NQ (Chicago): MyStartTrade 200, MyEndTrade 400 (default)
        @GC (New York):          MyStartTrade 300, MyEndTrade 500
    - Stop e target: StopPts / ProfitPts in punti di prezzo, oppure StopPct / ProfitPct
      in % del prezzo (se > 0 hanno la precedenza).
        @EC: StopPts 0.0075, ProfitPts 0.025 (i valori di Unger, default)
        GC, ES, NQ: StopPct 0.56, ProfitPct 1.9, StopPts 0, ProfitPts 0
      La % si calcola come in Mario_UngerTF_A.
    - I pattern si calcolano su ogni barra.
  ShowLog 1: una riga per ogni nuova posizione. }

Input: MyPtnLY(1), MyPtnSY(1), MyPtnLN(35), MyPtnSN(35);
Input: MyStartTrade(200), MyEndTrade(400), MyStartPause(1200), MyEndPause(1100);
Input: StopPts(0.0075), ProfitPts(0.025), StopPct(0), ProfitPct(0);
Input: ShowLog(0);

var: pLY(false), pSY(false), pLN(false), pSN(false);
var: mp(0), base(0), stopUSD(0), tgtUSD(0);

pLY = Mario_PtnBaseSA(MyPtnLY);
pSY = Mario_PtnBaseSA(MyPtnSY);
pLN = Mario_PtnBaseSA(MyPtnLN);
pSN = Mario_PtnBaseSA(MyPtnSN);

mp = marketposition;
if mp = 0 then base = close else base = entryprice;
if StopPct > 0 then stopUSD = base * StopPct / 100 * BigPointValue else stopUSD = StopPts * BigPointValue;
if ProfitPct > 0 then tgtUSD = base * ProfitPct / 100 * BigPointValue else tgtUSD = ProfitPts * BigPointValue;

if Time > MyStartTrade and Time < MyEndTrade and (Time < MyStartPause or Time > MyEndPause) then begin
	if pLY and pLN = false then buy ("TFB-L") next bar at highd(0) stop;
	if pSY and pSN = false then sellshort ("TFB-S") next bar at lowd(0) stop;
end;

setstopcontract;
if stopUSD > 0 then setstoploss(stopUSD);
if tgtUSD > 0 then setprofittarget(tgtUSD);
setexitonclose;

if ShowLog = 1 and mp <> 0 and (mp <> mp[1] or entryprice <> entryprice[1]) then
	Print("TFB ", Date:8:0, " ", Time:5:0, " mp=", mp:2:0, " entry=", entryprice:9:5,
		" hiD=", highd(0):9:5, " loD=", lowd(0):9:5, " stop$=", stopUSD:8:2, " tgt$=", tgtUSD:8:2);
