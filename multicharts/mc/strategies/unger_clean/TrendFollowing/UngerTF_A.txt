{ Mario_UngerTF_A — Trend Following di Unger, variante A (multi-day, "DevelopFineTune",
  video 4x03), per futures. Richiede la funzione Mario_PtnBaseSA. Spec: SPEC.md.

  Regole di Unger ai parametri finali (vedi UngerTF.txt per la trascrizione fedele):
    finestra MyStartTrade -> MyEndTrade, ieri giorno di indecisione (pattern 1);
    long  se (pattern 6 o 39) e non 18 -> buy stop al massimo di oggi;
    short se (pattern 4 o 39) e non 19 -> sellshort stop al minimo di oggi;
    stop e target fissi; nessuna uscita a fine giornata (stop, target o inversione).

  Cosa cambia rispetto al forex di Unger:
    - Orari nel fuso dell'exchange del chart. Unger: 04:00-13:30 New York.
        @EC, @ES, @NQ (Chicago): MyStartTrade 300, MyEndTrade 1230 (default)
        @GC (New York):          MyStartTrade 400, MyEndTrade 1330
    - Stop e target: StopPts / ProfitPts in punti di prezzo (x BigPointValue = $ a
      contratto), oppure StopPct / ProfitPct in % del prezzo (se > 0 hanno la precedenza).
        @EC: StopPts 0.011, ProfitPts 0.035 (i valori di Unger, default)
        GC, ES, NQ: StopPct 0.83, ProfitPct 2.6, StopPts 0, ProfitPts 0
      La % si calcola sul close finche' si e' flat (quindi sulla barra dell'ordine) e
      sul prezzo d'entrata quando si e' in posizione: e' costante per tutto il trade.
    - I pattern si calcolano su ogni barra (come in UngerCT).
  ShowLog 1: una riga per ogni nuova posizione. }

Input: MyPtnLY(6), MyPtnSY(4), MyPtnLN(18), MyPtnSN(19);
Input: MyStartTrade(300), MyEndTrade(1230), MyStartPause(1200), MyEndPause(1100);
Input: StopPts(0.011), ProfitPts(0.035), StopPct(0), ProfitPct(0);
Input: MyNoLongDay(0), MyNoShortDay(0), ShowLog(0);

var: p1(false), p39(false), pLY(false), pSY(false), pLN(false), pSN(false);
var: mp(0), base(0), stopUSD(0), tgtUSD(0);

p1  = Mario_PtnBaseSA(1);
p39 = Mario_PtnBaseSA(39);
pLY = Mario_PtnBaseSA(MyPtnLY);
pSY = Mario_PtnBaseSA(MyPtnSY);
pLN = Mario_PtnBaseSA(MyPtnLN);
pSN = Mario_PtnBaseSA(MyPtnSN);

mp = marketposition;
if mp = 0 then base = close else base = entryprice;
if StopPct > 0 then stopUSD = base * StopPct / 100 * BigPointValue else stopUSD = StopPts * BigPointValue;
if ProfitPct > 0 then tgtUSD = base * ProfitPct / 100 * BigPointValue else tgtUSD = ProfitPts * BigPointValue;

if Time > MyStartTrade and Time < MyEndTrade and (Time < MyStartPause or Time > MyEndPause) and p1 then begin
	if (pLY or p39) and pLN = false and dayofweek(date) <> MyNoLongDay then buy ("TF-L") next bar at highd(0) stop;
	if (pSY or p39) and pSN = false and dayofweek(date) <> MyNoShortDay then sellshort ("TF-S") next bar at lowd(0) stop;
end;

setstopcontract;
if stopUSD > 0 then setstoploss(stopUSD);
if tgtUSD > 0 then setprofittarget(tgtUSD);

if ShowLog = 1 and mp <> 0 and (mp <> mp[1] or entryprice <> entryprice[1]) then
	Print("TF ", Date:8:0, " ", Time:5:0, " mp=", mp:2:0, " entry=", entryprice:9:5,
		" hiD=", highd(0):9:5, " loD=", lowd(0):9:5, " stop$=", stopUSD:8:2, " tgt$=", tgtUSD:8:2);
