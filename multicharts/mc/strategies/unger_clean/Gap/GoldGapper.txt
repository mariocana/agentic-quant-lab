  @GC 5 min, dati TradeStation, grafico in ora di New York.

  FUNZIONI RICHIESTE (del corso, NON rinominate):
    _DayDefinition, Time00, TradesToday
  Si importano dal file GapsFunctions.pla (13. Codici/Gap/GapsFunctions),
  NON dai .txt: il _DayDefinition.txt (maggio 2016) ha una condizione di
  reset modificata che fa scattare il reset proprio sulla barra sBeg, e
  allora myhigh/mylow sarebbero il massimo e minimo di quella barra:
  la strategia non farebbe mai trade. Il .pla (febbraio 2016, quello
  dei video) resetta alla barra DOPO sBeg.

  REGOLE (Unger)
    1) Giornata personalizzata da sBeg a sEnd (attraversa la mezzanotte).
       Sulla barra delle sBeg: myhigh / mylow = massimo e minimo della
       giornata precedente, myopen = apertura di questa barra.
    2) Nella finestra sBeg -> sEnd, al massimo un ingresso per data:
       se myopen > myhigh  -> sell stop a myhigh (gap su che si richiude)
       se myopen < mylow   -> buy stop a mylow  (gap giu' che si richiude)
       I filtri di pattern sono COMMENTATI nel codice di Unger: input
       tenuti, non usati.
    3) Uscite: stop myloss $ per contratto, target myprofit $;
       MyExit 0 = flat a fine sessione, MyExit 1 = flat alla barra sEnd.

  ORARI: 20:05 New York = 19:05 Chicago; 19:00 NY = 18:00 CT;
         16:00 NY = 15:00 CT. Su chart in CT: sBeg 1905, sEnd 1800 (A)
         oppure 1500 (B).

  CHART: @GC 5 min, session template 17:00-16:00 CT senza pause,
         timezone Exchange (CT), Bar Magnifier 1 min ON.
  COSTI: 12.5$ per Contract ($2,50 + tick $10), slippage 0.
  ===================================================================== }

Input: sBeg(1905), sEnd(1800);
Input: myloss(2000), myprofit(0);
input: MyptnLY(41), MyPtnSY(41), MyPtnLN(42), MyPtnSN(42);   { non usati (come in Unger) }
input: Myexit(1);
input: ShowLog(0);

var: myHigh(0), myLow(0), myopen(0), mytimewindow(false), dh(0), dl(0);

{ _DayDefinition chiamata su ogni barra (funzione di serie con stato
  interno), letta sulla barra sBeg come nel codice di Unger }
dh = _DayDefinition(0, sBeg, sEnd, high, 2);
dl = _DayDefinition(0, sBeg, sEnd, low, 3);

if time = sBeg then begin
    myhigh = dh;
    mylow = dl;
    myopen = open;
    if ShowLog = 1 then
        Print("GAP DAY ", Date:8:0, " ", Time:5:0, " open=", myopen:8:2, " hi_ieri=", myhigh:8:2,
              " lo_ieri=", mylow:8:2, " gap=", IFF(myopen > myhigh, 1, IFF(myopen < mylow, -1, 0)):2:0);
end;

if sBeg > sEnd then mytimewindow = (time > sBeg or time < sEnd);
if sBeg < sEnd then mytimewindow = (time > sBeg and time < sEnd);

if mytimewindow and TradesToday(date) = 0 then begin
    if myopen > myhigh { and PtnBaseSA(myptnSY) = true and ptnbasesa(myptnSN) = False } then
        sellshort ("GG-S") next bar at myhigh stop;
    if myopen < mylow { and PtnBaseSA(myptnLY) = true and ptnbasesa(myptnLn) = False } then
        buy ("GG-L") next bar at mylow stop;
end;

setstopcontract;
if myloss > 0 then setstoploss(myloss);
if myprofit > 0 then setprofittarget(myprofit);

if MyExit = 0 then setexitonclose;
if MyExit = 1 and Time = sEnd then begin
    sell ("GG-XL") next bar at market;
    buytocover ("GG-XS") next bar at market;
end;
